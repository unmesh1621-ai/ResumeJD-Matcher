# Resume–JD Matcher (ICT 4442 Deep Learning Mini Project)

**Comparative Analysis of Deep Learning Architectures for Bias-Aware Resume–Job Description Matching**

Team: Unmesh Vardhan (230911030) · ShanmugSrinivas (230911394) · Tanmay Sharma (230911294)

Four document encoders from four architecture families are trained as Siamese (shared-weight) twin
networks under one common protocol. Each one maps a resume and a job description to vectors u and v.
The fit score comes from one of two scorers: **cosine(u, v)** or a small **interaction head** over
[u, v, |u−v|, u·v] (the Sentence-BERT classification feature set). The scorer for each model was chosen
on validation AUC.

| # | Model | Family | Owner |
|---|---|---|---|
| 1 | Siamese **MLP** over mean-pooled word embeddings | feed-forward baseline | Unmesh Vardhan |
| 2 | Siamese **1D-CNN** (multi-kernel, Kim 2014) | convolutional | ShanmugSrinivas |
| 3 | Siamese **BiLSTM** (masked mean-pooling) | recurrent | Tanmay Sharma |
| 4 | Fine-tuned **SBERT** bi-encoder (all-MiniLM-L6-v2) | Transformer | Unmesh Vardhan |

On top of the best encoder we add:
- an **explainability layer** (matched skills, missing skills and keyword overlap);
- a **bias audit** (counterfactual name-swap probe plus TPR gap);
- **adversarial debiasing** with a gradient-reversal layer.

## Results (held-out test split)

Every number below is generated by the scripts in this repo. It can be re-derived from the per-pair
`test_predictions.csv` files in `results/real/` (we checked: all 16 result folders recompute exactly).
The scratch models are mean ± std over 3 seeds; SBERT is one seed. Full tables, including precision,
recall and P@5, are in `results/real/comparison.md`.

| Model | Scorer (val-chosen) | Params | Val AUC | Accuracy | F1 | ROC-AUC | Within-resume AUC | P@1 | P@3 | Spearman ρ |
|---|---|---|---|---|---|---|---|---|---|---|
| MLP | cosine | 2.57 M | 0.685 | 0.582 ± 0.004 | 0.630 ± 0.052 | 0.616 ± 0.018 | 0.576 ± 0.028 | 0.484 ± 0.046 | 0.462 ± 0.030 | 0.188 ± 0.031 |
| 1D-CNN | interaction | 0.17 M* | 0.619 | 0.537 ± 0.025 | 0.606 ± 0.017 | 0.523 ± 0.024 | 0.455 ± 0.015 | 0.437 ± 0.034 | 0.459 ± 0.004 | 0.065 ± 0.050 |
| BiLSTM | cosine | 0.11 M* | 0.688 | 0.592 ± 0.012 | 0.624 ± 0.016 | 0.630 ± 0.015 | 0.592 ± 0.027 | 0.455 ± 0.018 | 0.430 ± 0.020 | 0.226 ± 0.025 |
| **SBERT** (MiniLM, fine-tuned) | interaction | 22.9 M | **0.898** | **0.673** | **0.676** | **0.762** | **0.687** | **0.690** | **0.633** | **0.442** |

\* Trainable parameters only. CNN and BiLSTM reuse the MLP's trained word embeddings as a frozen warm start.

**Within-resume AUC** is the AUC computed over the different JDs paired with the *same* resume,
averaged over resumes. It measures real resume↔JD matching. A model that ignores the job description
scores exactly 0.5 here.

### Baselines (same protocol, no matching model trained)

| Baseline | ROC-AUC | Within-resume AUC | P@1 | P@3 |
|---|---|---|---|---|
| Random ranking | 0.500 | 0.500 | — | 0.430 |
| **Resume-prior shortcut**: the resume's mean label in train, JD ignored | 0.657 | 0.500 | 0.380 | 0.498 |
| TF-IDF cosine | 0.575 | 0.551 | 0.549 | 0.522 |
| Zero-shot MiniLM (pretrained, no fine-tuning) | 0.622 | 0.631 | 0.620 | 0.580 |
| Zero-shot MPNet | 0.590 | 0.528 | 0.592 | 0.536 |

**Important caveat from our audit.** In the source dataset, 474 of the 477 test resumes also appear in
training, paired with *different* JDs; JDs never overlap. So a trivial shortcut that memorises how "good"
each resume is already reaches AUC 0.657, without reading the job description at all. The three scratch
models do **not** beat this shortcut on overall AUC. Their within-resume AUC is above 0.5 for MLP and
BiLSTM (0.58 / 0.59), so they do learn some genuine matching. The fine-tuned SBERT beats the shortcut on
both measures (0.762 overall, 0.687 within-resume).

### Ablations (scorer and backbone, chosen on validation only)

| Variant | Val AUC | Test AUC | Within-resume AUC |
|---|---|---|---|
| MLP, interaction head | 0.562 | 0.475 | 0.454 |
| 1D-CNN, cosine (3 seeds) | 0.573 | 0.580 | 0.539 |
| BiLSTM, interaction head | 0.657 | 0.568 | 0.584 |
| SBERT MiniLM, cosine | 0.877 | 0.740 | 0.677 |
| **SBERT MiniLM, interaction (selected)** | **0.898** | 0.762 | 0.687 |
| SBERT MPNet (all-mpnet-base-v2), interaction | 0.887 | **0.788** | **0.712** |

- **The interaction head** helps the pretrained SBERT. It hurts the scratch MLP and BiLSTM, where it
  lets the model memorise resumes: train loss falls while validation collapses. For the 1D-CNN it wins on
  validation (0.619 vs 0.573) but loses on test (0.523 vs 0.580). We kept the validation choice because
  choosing by test would leak. This is a validation→test generalisation failure: the validation split
  contains only 42 JDs.
- **The larger MPNet backbone** scores best on test (AUC 0.788, accuracy 0.735, F1 0.768). It is
  *not* the selected model because its validation AUC is slightly lower (0.887 vs 0.898). We report it
  as evidence that a stronger pretrained encoder helps, not as the headline number.

**Discussion.** Fine-tuning a pretrained Transformer is the only approach that clearly beats the
memorisation shortcut and does real JD-specific ranking: P@1 is 0.69, against 0.43 for a random ranking.
With only ~640 distinct training resumes, the scratch models overfit to resume identity. Train MSE keeps
falling while validation AUC peaks within 3–12 epochs. Of the three, BiLSTM is marginally the strongest.
The 1D-CNN is the weakest and least stable. Local n-gram detectors add little when fit depends on the
overall profile and seniority rather than on specific phrases.

**Error analysis** (`results/real/error_analysis/`):
- The scratch models' dominant failure is **false positives on *No Fit* pairs** (No-Fit error rate 44–56%).
  SBERT's errors are spread evenly across the three classes (32–34%).
- 164 test pairs are misclassified by all four models, and 108 of them are *No Fit*.
- Errors fall as resumes get longer. For MLP the error rate is 48% on short resumes vs 37% on long ones.
- MLP and BiLSTM make very similar mistakes (error Jaccard 0.67). SBERT's errors overlap much less
  with every other model (Jaccard ≈ 0.31–0.33).

### Bias audit and adversarial debiasing (`results/real/bias_probe_report.json`, `fairness_report.json`)

Each test resume is duplicated with a group-A or group-B first name prepended; otherwise the two copies are
identical. A linear probe trained on disjoint resumes *and disjoint names* tries to recover the group
(chance = 0.50). We also measure the decision flip rate between the two copies and the TPR gap.

| Encoder | Probe acc. | Decision flip rate | TPR gap (A−B) | Test AUC |
|---|---|---|---|---|
| MLP | 0.504 | 0.005 | −0.003 | 0.619 |
| 1D-CNN | 0.542 | 0.035 | +0.034 | 0.557 |
| BiLSTM | 0.506 | 0.004 | −0.002 | 0.626 |
| SBERT (selected) | **0.605** | 0.008 | −0.002 | 0.762 |
| SBERT control (λ = 0, same extra training) | 0.592 | 0.002 | 0.000 | 0.768 |
| **SBERT adversarially debiased (GRL, λ = 1)** | **0.527** | 0.005 | +0.001 | 0.763 |

The Test AUC column is from the seed-42 checkpoint that the audit loads.

- MLP and BiLSTM carry no name signal, because the names are mostly out of their vocabulary.
- The interaction-head 1D-CNN's scores sit close to its threshold, so the name swap flips 3.5% of decisions.
- SBERT's embedding leaks the name group (0.605 on unseen names), from its pretrained knowledge of first names.
- Gradient-reversal training pushes the probe from 0.605 to 0.527 **without hurting matching AUC**
  (0.762 → 0.763). The control run (0.592) shows most of the drop comes from the adversary, not from the
  extra training.
- Caveat: SBERT's score-level effects were already small (under 1% TPR gap), and the probe test set is
  954 embeddings, roughly ±3% at 95% confidence.

## Data

The final results use **real** resume–JD pairs from the public HuggingFace dataset
[`cnamuangtoun/resume-job-description-fit`](https://huggingface.co/datasets/cnamuangtoun/resume-job-description-fit).
It has 8,000 pairs of real resumes and real job postings, each labelled *No Fit*, *Potential Fit* or
*Good Fit*. The Kaggle datasets named in the synopsis needed API credentials that weren't available,
and this dataset provides the direct pair-level supervision the synopsis asked for.

Preprocessing is in `data/prepare_real.py`:
- Clean the text: unicode-normalise; mask e-mails, URLs and phone numbers; drop duplicates.
- Map labels to graded targets: No Fit → 0.0, Potential → 0.5, Good → 1.0. A pair counts as a match if its label is ≥ 0.5.
- Split: the dataset's own test file is the **held-out test set**, and validation (15%) is carved from train.
  **No job description appears in more than one split**, so the test set measures generalisation to unseen jobs.

| Split | Pairs | Unique resumes | Unique JDs |
|---|---|---|---|
| train | 5,338 | 636 | 238 |
| val | 896 | 336 | 42 |
| test | 1,759 | 477 | 71 |

The earlier synthetic dataset from the interim report is still reproducible: `python data/generate_dataset.py`,
then `--data synthetic` on the scripts. Its results are in `results/` (top level, interim).

## Common evaluation protocol

All four models use:
- the same split;
- the same objective: MSE between the fit score and the graded label;
- checkpoint selection on validation ROC-AUC;
- a decision threshold tuned on **validation** and applied unchanged to test.

Two settings are hyper-parameters chosen on **validation AUC only**, and test is never used for any choice:
- the scorer for each model (cosine vs interaction head);
- the SBERT backbone (`src/select_sbert.py`).

Reported test metrics:
- Accuracy, Precision, Recall, F1 and ROC-AUC;
- **within-resume AUC**;
- **Precision@k**: resumes ranked per job, k = 1/3/5, shown next to the random-ranking value;
- Spearman ρ against the graded label.

The three scratch-trained models are run with 3 seeds (mean ± std). They share one tokenizer and
vocabulary (20k tokens, 512-token sequences) built on the train split only. SBERT uses its pretrained
tokenizer: 512 tokens for MiniLM, and MPNet's native 384.

## Layout

```
data/
  download_real.py      fetch the real dataset
  prepare_real.py       cleaning, label mapping, JD-disjoint split -> pairs_real.csv
  skill_vocab_real.csv  ~200 skills + aliases for the explainability layer
  generate_dataset.py   (interim) synthetic dataset generator
src/
  models.py             the 4 Siamese encoders + cosine / interaction-head scorer
  preprocessing.py      shared tokenizer / vocab for the scratch models
  train.py              common training + test evaluation loop
  baselines.py          resume-prior shortcut, TF-IDF, zero-shot encoders
  select_sbert.py       picks the final SBERT (backbone x scorer) on validation AUC
  evaluate.py           main / ablation / baseline tables, ROC/bar plots, error analysis
  explainability.py     matched / missing skills
  bias_probe.py         counterfactual name-swap bias audit (all encoders)
  debias.py             gradient-reversal adversarial debiasing of SBERT
  model_io.py           load any trained encoder
  predict.py            CLI: score a resume (pdf/docx/txt) against a JD
app.py                  Streamlit demo
run_all.py              whole pipeline in one command
scripts/train_all.ps1   the exact training sequence used (Windows)
results/real/           final models: mlp/ cnn/ bilstm/ sbert/ (+ seeds/), comparison*.md/csv, plots,
                        error_analysis/, bias_probe_report.json, fairness_report.json, logs/
results/real/ablation_* the non-selected scorer variants; sbert_mpnet_interaction/ = MPNet run
results/real/baselines/ baseline predictions + metrics
```

## Reproducing

```bash
pip install -r requirements.txt          # GPU: install the CUDA torch build first
python run_all.py                        # data -> baselines -> all variants -> selection -> evaluation -> fairness
# or step by step (see scripts/train_all.ps1 for every variant and seed):
python data/download_real.py && python data/prepare_real.py
python src/baselines.py
python src/train.py --model mlp --head cosine            # MLP first (its embeddings warm-start CNN/BiLSTM)
python src/train.py --model cnn --head interaction
python src/train.py --model bilstm --head cosine
python src/train.py --model sbert --backbone minilm --head interaction --out ablation_interaction/sbert_minilm
python src/select_sbert.py                               # copies the val-best SBERT to results/real/sbert
python src/evaluate.py
python src/explainability.py
python src/bias_probe.py
python src/debias.py
# demo
python src/predict.py --resume my_resume.pdf --jd-text "We are hiring a data analyst ..."
streamlit run app.py
```
