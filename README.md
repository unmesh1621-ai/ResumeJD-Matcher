# Resume–JD Matcher (ICT 4442 Deep Learning Mini Project)

Comparative analysis of four deep learning architectures — Siamese MLP, 1D-CNN, BiLSTM, and a
fine-tuned SBERT (all-MiniLM-L6-v2) bi-encoder — for bias-aware resume–job-description matching,
with an explainability layer (matched/missing skills) and a bias-probing audit for demographic-proxy
leakage.

See `report/Interim_Report.docx` for the full interim writeup.

## Status (interim)

All four encoders are implemented (`src/models.py`), trained, and validated
(`src/train.py --model {mlp,cnn,bilstm,sbert}`) on a **synthetic, self-generated** resume–JD pair
dataset (`data/generate_dataset.py`) — Kaggle API credentials were not available in the development
environment, so this stands in for the three Kaggle datasets named in the project synopsis, at a much
smaller scale (150 resumes / 150 JDs / 1,200 pairs vs. the 5,000–8,000 pairs specified). This is
documented explicitly as a limitation in the interim report, not hidden.

Validation results:

| Model | Val Accuracy | Val AUC |
|---|---|---|
| MLP | 91.1% | 0.953 |
| 1D-CNN | 68.9% | 0.837 |
| BiLSTM | 90.0% | 0.957 |
| SBERT (fine-tuned) | 93.3% | 0.977 |

Explainability (`src/explainability.py`) and a bias probe (`src/bias_probe.py`) are also implemented.
**Not yet done:** real Kaggle data, held-out test-set evaluation, error analysis, Precision@k,
adversarial debiasing — see "Remaining Work" in the interim report.

## Layout

```
data/        synthetic dataset generator + generated CSVs
src/         shared preprocessing, 4 model architectures, training loop, explainability, bias probe
results/     per-model metrics/plots + bias probe report (generated by src/train.py, src/bias_probe.py)
report/      Interim_Report.docx + the script that generates it
```

## Reproducing

```
pip install torch transformers
python data/generate_dataset.py
python src/train.py --model mlp
python src/train.py --model cnn
python src/train.py --model bilstm
python src/train.py --model sbert
python src/explainability.py
python src/bias_probe.py
```
